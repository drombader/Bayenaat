# بيّنات — منهج «ترياق» تفاعلياً

منهجٌ تعليميّ مختصر من كتاب **«ترياق: نحو معالجة تأصيلية للشبهات الفكرية»** —
إعداد د. دلال البعيجان، ود. عواطف العبدالهادي، ود. لولوة الوهيب، ود. منيرة الصالح،
وأ. سمية السميط. والكتاب الأصل تأليف د. مطلق الجاسر.

موقعٌ ساكنٌ قائمٌ بذاته: لا React ولا Next ولا أي اعتمادٍ خارجيّ سوى الخطوط.

```
.
├── index.html        الصفحة كلها: المحتوى والتنسيق والبرمجة والمتن (١٧٣ صفحة)
├── img/              ١٧ صورة من عرض الكتاب التقديمي
├── gen-config.mjs    يولّد config.js من متغيرات البيئة قبل النشر
├── supabase/
│   └── schema.sql    جداول المزامنة وسياسات الأمان
└── config.js         (يُولَّد وقت البناء — غير متتبَّع في git)
```

| القسم | ما فيه |

| التمارين | ٣٣ سؤالاً مصحَّحاً فور الإجابة، وتقريرٌ للمعلّم |
| الأنشطة | ٤ أوراق أنشطةٍ صفّية بمؤقّت |
| المصطلحات | ٢٧ بطاقةً تُقلب وتُصنَّف |

## التصفّح محلياً

انقر `index.html` نقرةً مزدوجة. تعمل الصفحة كاملةً بالتخزين المحلي؛ ولا يُحمَّل
`config.js` حينئذٍ، فتبقى بلا مزامنة — وهو المقصود.

## النشر

النطاق المعتمد: **bayenaat.com**، وتُخدَّم الصفحة على جذره.

### ١) مشروع Vercel

**Add New… → Project** واختر هذا المستودع. واحرص أن يكون المشروع في نطاق
حسابك الشخصي، لا في فريقٍ آخر.

| الإعداد | القيمة |
| --- | --- |
| Project Name | `bayenaat` |
| Framework Preset | `Other` |
| Root Directory | `.` (الجذر — اتركه كما هو) |
| Build Command | `node gen-config.mjs` |
| Output Directory | `.` |

### ٢) ربط النطاق

**Settings → Domains** وأضف `bayenaat.com` ثم `www.bayenaat.com`، ثم اضبط
عند مسجّل النطاق سجلَّي `A` للاسم `@` و`CNAME` للاسم `www` بالقيم التي
تعرضها تلك الصفحة — فهي المرجع، ونطاق عناوين Vercel يتوسّع من حينٍ لآخر.
وانتشار DNS قد يستغرق دقائق إلى ساعات.

#### النطاق مشترى من GoDaddy

يربط GoDaddy النطاق الجديد بصفحة عرضٍ من أداة **Websites + Marketing** عنده،
فتراه يفتح موقعاً مبدئياً لم تصنعه. لا يحتاج ذلك حذفاً ولا إلغاءً: في
**My Products → Domains → DNS** بدّل سجلَّ `A` للاسم `@` — وهو عندهم
**WebsiteBuilder Site** أو **Parked** — بالعنوان الذي تعرضه Vercel. يفصل هذا
التبديلُ النطاقَ عن أداة البناء ويوجّهه إلى الموقع الجديد.

واحذف أي سجلِّ `A` أو `CNAME` آخر على `@` أو `www` يخالف ما تطلبه Vercel،
فالسجلّان المتعارضان يجعلان الفتح متذبذباً. وتصدر شهادة HTTPS تلقائياً بعد
انتشار السجلات.

ثم من **Settings → Domains**: اجعل `www.bayenaat.com` بـ **Redirect to**
`bayenaat.com`، و`bayenaat.com` بـ **No Redirect**.

### ٣) متغيرات البيئة (اختيارية)

بدونها تعمل الصفحة بالتخزين المحلي وحده. وللمزامنة أضف في **Settings →
Environment Variables**:

```
NEXT_PUBLIC_SUPABASE_URL       = https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY  = eyJhbGciOi...
```

ثم أعد النشر ليقرأها `gen-config.mjs`. والمفتاح هو **anon key** العلني وحده؛
لا تضع `service_role` هنا فهو يتجاوز كل سياسات الأمان.

## قاعدة البيانات

شغّل `supabase/schema.sql` في **SQL Editor**. يعرّف أربعة جداول:
`tiryaq_progress` و`tiryaq_quiz` و`tiryaq_cards` و`tiryaq_notes`، وعرضاً
إحصائياً `tiryaq_question_stats` يبيّن أكثر الأسئلة إشكالاً على الطلبة.

والتمييز بمعرّف جلسةٍ يُولَّد في المتصفح، لا بتسجيل دخول — فسياسات RLS تمنح
`anon` قراءةً وكتابة على كل الصفوف. وهو مناسبٌ لبيانات تمارين؛ فإن أردت عزلاً
حقيقياً بين الطلبة فاربطها بـ Supabase Auth واجعل الصفوف على `auth.uid()`.

## ما يُحفظ في المتصفّح

`tiryaq.state` تقدّم القراءة والعلامات · `tiryaq.quiz` إجابات التمارين ·
`tiryaq.cards` تصنيف البطاقات · `tiryaq.notes` ملاحظات المعلّم ·
`tiryaq.edits` تعديلات النصّ · `tiryaq.session` معرّف الجلسة.

## تعديل المحتوى

البيانات داخل `index.html` في `CURRICULUM` و`DIAGRAMS` و`QUIZ` و`ACTIVITIES`
و`TERMS` و`SOURCES`، والمتن في كتلة
`<script id="tiryaq-data" type="application/json">`.

## ملاحظتان على المصادر

- **المخططات** السبعة عشر مبنيّةٌ من نصّ الكتاب بـ HTML/CSS، لا منقولةً من صورة.
  وشعار الجمعية غير مُدرَج؛ محلّه نجمةٌ ثمانيةٌ بـ SVG.
- **المتن** مستخرَجٌ آلياً من النسخة المصوّرة، وفي ترتيب بعض الأسطر اضطرابٌ من
  الاستخراج لا من الأصل؛ ولهذا صيغ المحتوى المنظَّم صياغةً جديدة لا نسخاً.
